# Dokumentācija par programmu „Mājasdarbu atgādinātājs”

## 1. Programmas nosaukums

„Mājasdarbu atgādinātājs”

## 2. Problēmas apraksts

Daudzi skolēni ikdienā aizmirst par uzdotajiem mājasdarbiem, kontroldarbiem un projektu nodošanas termiņiem. Dažreiz skolēni pieraksta uzdevumus, bet vēlāk aizmirst tos izpildīt. Tas var negatīvi ietekmēt skolēnu sekmes.

## 3. Programmas mērķis

Programmas mērķis ir palīdzēt skolēniem organizēt savus mājasdarbus un atcerēties par to izpildīšanas termiņiem. Programma automātiski atgādina skolēnam par tuvojošos mājasdarba nodošanas laiku.

## 4. Programmas funkcijas

Programmā būs pieejamas šādas funkcijas:

- Mājasdarbu pievienošana – skolēns var ievadīt priekšmetu un mājasdarba aprakstu.
- Datuma izvēle – skolēns var norādīt, līdz kuram datumam jāizpilda uzdevums.
- Atgādinājumi – programma atgādina par mājasdarbiem, kuru termiņš tuvojas.
- Uzdevumu saraksts – skolēns var apskatīt visus savus uzdotos mājasdarbus.
- Uzdevuma pabeigšana – pēc darba izpildīšanas skolēns var atzīmēt to kā pabeigtu.
- Uzdevuma dzēšana – skolēns var izdzēst nevajadzīgus vai izpildītus uzdevumus.

## 5. Programmas lietotāji

Programma galvenokārt paredzēta skolēniem, kuri vēlas labāk organizēt savu mācību procesu un neaizmirst par mājasdarbiem.

## 6. Nepieciešamie rīki

Programmas izveidošanai var izmantot:

- HTML – programmas struktūras izveidošanai.
- CSS – programmas dizaina veidošanai.
- JavaScript – programmas funkciju un atgādinājumu darbībai.
- Visual Studio Code – programmas koda rakstīšanai.

## 7. Programmas darbības princips

1. Skolēns atver programmu.
2. Skolēns ievada mājasdarba nosaukumu.
3. Izvēlas mācību priekšmetu.
4. Norāda mājasdarba izpildes termiņu.
5. Saglabā uzdevumu.
6. Programma saglabā uzdevumu sarakstā.
7. Kad tuvojas izpildes termiņš, programma parāda atgādinājumu.
8. Pēc mājasdarba izpildīšanas skolēns atzīmē uzdevumu kā pabeigtu.

## 8. Sagaidāmais rezultāts

Pēc programmas izveidošanas skolēniem būs vienkāršs un ērts digitāls palīgs, kas palīdzēs atcerēties mājasdarbus un plānot savu laiku. Programma samazinās iespēju aizmirst svarīgus uzdevumus un palīdzēs uzlabot mācību procesa organizēšanu.

## 9. Secinājumi

Programma „Mājasdarbu atgādinātājs” ir noderīgs digitāls risinājums skolēnu ikdienas problēmai. To var izveidot arī skolēns bez lielas programmēšanas pieredzes. Šāda programma palīdzēs skolēniem kļūt organizētākiem, atbildīgākiem un savlaicīgi izpildīt uzdotos mājasdarbus.
